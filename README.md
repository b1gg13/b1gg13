# `HOW I THINK`

```python
def solve(problem):

    understand(problem)

    pieces = break_into_smaller_parts(problem)

    solution = build(pieces)

    while not solution.is_good_enough():

        test(solution)

        if solution.breaks():
            understand_why(solution)
            fix(solution)

        refactor(solution)

    return solution
```

> **A bug is not just something to remove.
> It is something to understand.**
